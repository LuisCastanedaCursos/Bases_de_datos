📚 Guía rápida de PostgreSQL

Consulta sintaxis y tipos de datos. Los ejemplos usan tablas distintas a las misiones.

1. Crear una tabla — CREATE TABLE

Define el nombre de la tabla, sus columnas y los tipos de datos.

CREATE TABLE profesores (
  id SERIAL,
  nombre VARCHAR(60),
  asignatura TEXT,
  edad INTEGER
);

2. Insertar datos — INSERT INTO

Indica columnas y valores. Para insertar varias filas, separa los grupos de paréntesis con comas.

INSERT INTO profesores (nombre, asignatura, edad)
VALUES
  ('Laura', 'Historia', 32),
  ('Pedro', 'Arte', 29);

3. Consultar — SELECT

* muestra todas las columnas. También puedes elegir columnas.

SELECT * FROM profesores;

SELECT nombre, edad FROM profesores;

4. Filtrar — WHERE

Obtén solo las filas que cumplan una condición. Las cadenas de texto van entre comillas simples.

SELECT nombre FROM profesores
WHERE edad >= 30;

SELECT * FROM profesores
WHERE asignatura = 'Arte';

5. Varias condiciones — AND

Con AND, ambas condiciones deben cumplirse.

SELECT nombre FROM profesores
WHERE edad > 25 AND asignatura = 'Arte';

6. Varias condiciones — OR

Con OR, es suficiente con que una de las dos condiciones se cumpla. También se incluyen filas cuando ambas son verdaderas.

SELECT nombre FROM profesores
WHERE edad < 25 OR asignatura = 'Arte';

7. SERIAL: ID automático

SERIAL genera números consecutivos para una columna cuando no proporcionas su valor. En PostgreSQL, también existen SMALLSERIAL y BIGSERIAL.

CREATE TABLE talleres (
  id SERIAL PRIMARY KEY,
  titulo VARCHAR(80)
);

INSERT INTO talleres (titulo)
VALUES ('Pintura'), ('Teatro');

Los identificadores se generan automáticamente: no escribas id en el INSERT. Nota: esta guía muestra sintaxis real de PostgreSQL; el simulador del juego admite solamente un subconjunto.

8. Tablas de verdad: AND y OR

Imagina que cada condición del WHERE puede ser verdadera (V) o falsa (F). Así se decide si una fila aparece en la consulta:

AND — deben cumplirse las dos

Condición ACondición BA AND B
VVV ✓
VFF ✗
FVF ✗
FFF ✗

Ejemplo: una persona tiene más de veinticinco años y enseña Arte. Solo aparece si las dos afirmaciones son verdaderas.

OR — basta con una

Condición ACondición BA OR B
VVV ✓
VFV ✓
FVV ✓
FFF ✗

Ejemplo: una persona tiene menos de veinticinco años o enseña Arte. Aparece si cumple una o ambas condiciones.

Importante en PostgreSQL: una comparación también puede producir NULL (valor desconocido). Estas tablas muestran primero los casos básicos V/F. Al combinar operadores, AND se evalúa antes que OR.

10. Operadores y recordatorios

= igual · != o <> diferente · > mayor · < menor · >= mayor o igual · <= menor o igual.

Termina cada sentencia con ;. Usa comillas simples para textos, pero no para números: 'Ana' y 25. Puedes ejecutar SQL con Ctrl + Enter.
